# Configuration

Project config uses relative paths and resolves them dynamically. Validation
commands declare `cwd` and `argv`.

The V1 orchestration defaults are generated by `lfg init --yes`:

- `hermes.primary_model`, `hermes.fallback_model`, and
  `hermes.allow_fallback` describe the planning control plane.
- `providers.<name>.priority`, `providers.<name>.capabilities`, and
  `providers.<name>.cooldown_seconds` drive provider selection and recovery.
- `execution.require_plan_approval` keeps generated plans approval-gated.
- `execution.preserve_partial_work_on_handoff` keeps dirty worktrees and
  branches available for the next provider.
- `monitoring.git_graph` controls whether `lfg dashboard` includes the compact
  Git graph.

Work packages support `id`, `name`, `objective`, `dependencies`, `owned_paths`,
`forbidden_paths`, legacy `acceptance_tests`, v2 `acceptance_criteria`,
structured `validation_commands`, `preferred_providers`, `model_profile`,
`reviewer_profile`, `risk_level`, `context_refs`, `merge_policy`,
`approval_required`, `review_required`, `branch`, `worktree`, and
`status_notes`. Runtime truth lives in `.lfg-runtime/state/tasks.json`;
`status_notes` is only planner/user context.

Approved v2 plans also freeze `.lfg/contract_freeze_manifest.yaml`,
`.lfg/model_assignment.yaml`, `.lfg/dependency_graph.mmd`,
`.lfg/ownership_matrix.csv`, and generated `.lfg/agent_prompts/`.

## LFG v2 Launch Defaults

`lfg launch` stores launch-time choices in
`.lfg-runtime/state/session-profile.json`. The default preset uses valid model
refs for the installed adapters:

- Hermes orchestrator: `codex:gpt-5.5?reasoning=high`
- Architect/planner: `antigravity:claude-opus-4.6-thinking`
- Codex worker: `codex:gpt-5.5?reasoning=high`
- Antigravity worker: `antigravity:gemini-3.5-flash-low`
- Composer worker: `composer:grok-composer-2.5-fast`

Hermes integration is generated under `.lfg-runtime/hermes/<profile>/` and is
not tracked. LFG writes a Hermes-native `config.yaml` with `mcp_servers.lfg`,
a `SOUL.md` identity file containing LFG factory instructions, and a local
`skills/lfg-factory/SKILL.md` for discoverability. The launch command uses
`HERMES_HOME=<runtime-profile> hermes chat --cli`; it does not pass unsupported
`--config`, `--toolsets mcp`, or `--skills lfg-factory` flags.
