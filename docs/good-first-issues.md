# Good first issues

These bounded starter tasks are suitable for contributors without inventing GitHub issues:

- Add contract fixtures for an optional field and update its compatibility note.
- Add CLI help/exit-code tests for an existing command.
- Improve an error message with a regression test.
- Add a fake-provider failure classification fixture.
- Document a tested platform-specific setup failure.

Recommended repository labels: `good first issue`, `help wanted`, `bug`, `documentation`, `provider`, `runtime`, `contracts`, `breaking change`, `security`, and `testing`.
